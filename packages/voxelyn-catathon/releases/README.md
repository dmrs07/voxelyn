# CATATHON — playable slice builds

One zip per roguelite slice, each a snapshot of `dist/` at the moment that
slice shipped (unzip and serve the folder with any static file server —
e.g. `npx serve .` — then open it on a phone or a touch-emulating browser).

| build | what it plays like |
| --- | --- |
| `catathon-slice-a.zip` | the fixed match: morale, pet memory, task decisions, playable pitch, 5-dimension scoring |
| `catathon-slice-b.zip` | + the generator: recruitment email, 30 breeds, tiers, traits, currencies, layouts, i18n (EN/PT) |
| `catathon-slice-c.zip` | + the reason to return: gear shop, social events, prize, career/quick/daily modes, achievements |
| `catathon-slice-d.zip` | + depth: compatibility, mentorship, sponsors, special categories, the rival dogs, cross-run consequences |

Only the latest zip matches the current source; the earlier ones are kept
as historical playables — the devlogs in `../docs/devlog/` narrate each.
