# Voxelyn 0.1.1 Release Notes

Date: 2026-02-19

## Highlights

This release focuses on npm publication readiness and packaging reliability for the public Voxelyn modules.

## What shipped

### Publish workflow
- Added root scripts to run package publishing in a fixed order:
  - `publish:dry-run`
  - `publish:packages`
- Included prepublish build hooks in each package so builds run automatically during publish.

### Package metadata
- Updated package versions to `0.1.1`:
  - `@voxelyn/core`
  - `@voxelyn/cli`
  - `@voxelyn/ai`
  - `@voxelyn/animation`
- Marked publishable packages as public with `publishConfig.access = "public"`.

### Packaging fix (`@voxelyn/animation`)
- Fixed TypeScript output boundaries by setting `rootDir: "./src"`.
- Removed local TS path mapping to `../voxelyn-core/src/*` to avoid bundling foreign sources.
- Ensured clean builds by deleting `dist` before compiling.

### Sprite pipeline follow-up
- Added deterministic GPT spritesheet import support for the roguelike actor atlases.
- Regenerated hero and enemy atlas assets from the GPT animated sheets and marked those manifests as baked-motion sources.
- Added hit and death atlas clips for enemies.
- Added support for `spritesheetgen` cutter exports and switched the Excavator atlas to the cleaner cutter sheet.

## Published packages

- `@voxelyn/cli@0.1.1`
- `@voxelyn/ai@0.1.1`
